# 당근 대형 가구 거래 · AS-IS / TO-BE 시안

케이스 스터디에 쓰는 원본 시안이에요. 사이트에 배포되지 않는 폴더라, 페이지에 쓸 때는 `public/images/karrot-large-furniture/`에 webp로 변환해 넣어요.

| 폴더 | 내용 |
|---|---|
| `as-is/` | 실제 당근 앱 캡처(대형가구 검색 → 상품 상세). 판매자 닉네임, 거래 장소 주소·지도, 캡처한 사람의 닉네임·동네는 가렸어요. |
| `before-after/` | 유아이볼의 실제 당근 화면(글쓰기·상세·채팅)과 개선안을 짝지은 비교. Figma 🔍 Before · After 페이지 요약 이미지 포함. |
| `to-be-full-scroll/` | 개선안 20개 화면의 전체 스크롤 PNG(780px 폭, 2x). iOS 상태 바·노치·홈 인디케이터 포함. |

프로토타입은 `public/proto/karrot/`에 있어요. `?sc=<시나리오>`(예: `?sc=detail-partial`, 구매자 흐름 처음부터는 `?sc=home`)는 화면 하나만, 주소만 열면 판매자·구매자 29개 화면 전체, `#full`을 붙이면 전체 스크롤 보기로 열려요.
