## 4. 레이아웃 제안

### Home
| | 줄일 것 | 확대할 것 | 바꿀 레이아웃 |
|---|---|---|---|
| Hero | 소개 3줄→1줄 | 대표 UI를 폭 1200px 풀폭으로 한 장씩 크게(띠 대신 폰 2대, 잘림 없이) | 표지(타이포) 100vh → 바로 아래 UI 쇼케이스. Featured trigr와 중복 안 되게 Hero는 **지도+홈** 2화면, Featured는 **생성·인증·보상** |
| Featured trigr | 설명 문단 삭제, 키워드 3개만 | 폰 4대 → **3대 + 중앙 1대를 1.4배** (비균일) | 풀폭 쇼케이스 유지, 하단에 "생성자·참여자 흐름 2줄 미니 다이어그램" |
| Featured NODI | 문제 문장 1줄 + 키워드 3개 | AI 제안→사용자 확인→확정 화면 3장을 가로 순서로 연결 | 분할 에디토리얼 유지, 오른쪽 패널을 "AI 제안/사용자 결정" 2열 어노테이션으로 |
| Selected | 카드당 키워드 삭제(프로젝트명·1문장·UI·유형·링크만) | 카드 UI 크기 +30% | 3카드 비대칭(1 large + 2 small) |
| Approach | 본문 2문장→1문장 | 화면을 1개당 큰 1장 | 3행 교차 배치 유지, 텍스트 폭 축소 |

### trigr (현재 7챕터 → Hero + 01 Challenge-Context + 02 Evolution/Decisions + 03 Final UI + 04 Reflection 4블록으로 압축, 구조 재배치)
- **줄일 것:** Context 3카드 본문(각 3문장→1문장), Evolution 3단계 카드·구조화/확장/고도화 카드 통합, 챕터별 lead 문장 삭제, 본문 요약 후 원문은 "원문 보기" 접이식.
- **확대할 것:** 미션 생성 4단계(PDF 재추출 후 폭 280px 이상), 지도/리스트 탐색 각 1장 큰 화면, 상금 지급 3단계, 인증 상세.
- **레이아웃:** ① Evolution: 가로 타임라인 + 각 단계 핵심 변경 1줄(현재 3행 표 → 1행) ② Decisions: **세 결정 = 큰 UI 1장 + 주석 2개**(생성 / 탐색 / 인증·보상), 균일 스트립 제거 ③ 실제 출시 기능과 사후 개선 제안은 색·라벨로 계속 분리.

### NODI (메시지: AI는 이해하고, 사용자는 결정한다)
- **줄일 것:** Overview·Challenge 본문(인터뷰 3가지 스트레스 카드는 유지, 설명문 삭제), Decision 4개 본문 각 3→1문장, 검증 본문.
- **확대할 것:** AI 조건 확인 카드(조건 확인), 추천 시간 + 추천 이유, 최종 검토→저장 완료(후속 처리 구분) — 각 큰 화면 + 짧은 주석.
- **레이아웃:** Hero 폰 4대 균일 → **1대 크게 + 어노테이션**(AI 제안/사용자 수정 가능 지점). Design Exploration을 "AI가 하는 일 | 사용자가 정하는 일" 2열 비교 UI로(실제 화면 기준). 상태 화면(AI 실패·후보 없음)은 한 줄 스트립 유지.
