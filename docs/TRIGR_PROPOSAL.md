# trigr 상세 페이지 리디자인 제안

기준 자료: 「2026_포트폴리오_노승우_」 PDF 13~27페이지(페이지는 이미지 슬라이드이며 텍스트는 렌더링해 직접 확인), 데스크톱 `포트폴리오 프로젝트 UI/trigr` PNG 49장.
(참고: PDF 13페이지는 다른 프로젝트(일정 조율)이며 trigr 범위가 아님.)

## 콘텐츠 원칙
- PDF에 없는 수치·사용자 피드백·성과는 쓰지 않는다. 텍스트는 PDF 문구를 그대로 쓰고 간결하게 배치한다.
- 출시 기능과 사후 개선 제안(PDF 21p)을 구분해 표기한다. 서비스는 현재 운영되지 않음을 Hero에 명시한다.
- 기여 범위는 PDF의 단계별 "나의 역할" 문구만 사용한다.

## 7챕터 와이어프레임
```
01 Hero                : 좌 제목·부제(PDF 14p)·운영 종료 배지·메타 / 우 PDF 대표 UI(두 대의 폰)
02 Context & My Role   : "전체 경험을 설계" + 01·02·03 카드(15p) + 프로젝트 목표 다이어그램(18p)
03 Product Evolution   : 가로 타임라인 4열(초기 기획·1~3차) × 서비스 목표/주요 변화/나의 역할(16p) + 구조화→확장→고도화(17p)
04 Experience Arch.    : 생성자·참여자 2개 레인 × 4단계(19p), 각 단계를 실제 화면과 연결
05 Design Decisions    : 미션 생성(4단계) / 탐색(지도·리스트) / 인증(방식 선택→등록) / 운영 관리 / 보상 — 단계별 화면
06 UI Craft            : 핵심 UI 확대 + 화면에서 확인되는 컴포넌트 + 마이페이지 + (추가 자료 필요 항목)
07 Reflection          : 사후 개선 제안 Current ↔ Proposed 좌우 비교(21p) + What I Learned(27p)
```
